# 🚀 DevSecOps CI/CD Pipeline Project

## 📌 Project Overview

This project demonstrates a complete **DevSecOps CI/CD pipeline** where code is automatically built, tested, scanned for security issues, containerized, and deployed to AWS EC2.

The goal is to integrate **Development + Security + Deployment** into one automated workflow.

## 🛠️ Tools & Technologies Used

- GitHub (Source Code Management)
- Jenkins (CI/CD Automation)
- Docker (Containerization)
- SonarQube (Static Code Analysis)
- OWASP Dependency Check (Vulnerability Scanning)
- Trivy (Docker Image Security Scanning)
- AWS EC2 (Deployment Platform)
- Linux (Kali Environment)

---

## 🔐 DevSecOps Security Integration

- **SonarQube** → Detects code quality issues and bugs in source code  
- **OWASP Dependency Check** → Finds vulnerable libraries and dependencies  
- **Trivy** → Scans Docker images for OS-level and package vulnerabilities (CVE detection)

---

## 📌 CI/CD Pipeline Flow

```text
Developer (VS Code)
        ↓
GitHub (Source Code Repository)
        ↓
Jenkins (CI/CD Pipeline)
        ↓
SonarQube (Code Quality Analysis)
        ↓
OWASP Dependency Check (Security Scan)
        ↓
Docker Build (Image Creation)
        ↓
Trivy Scan (Container Security Check)
        ↓
AWS EC2 Deployment (Live Application)
