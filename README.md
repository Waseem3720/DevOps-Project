# DevOps Project 🚀

## CI/CD Pipeline Status

This project demonstrates a complete DevOps pipeline by using:

- GitHub
- Jenkins
- Docker
- Trivy Security Scanner
- AWS EC2 Deployment

---

## Pipeline Flow

1. Code pushed to GitHub
2. Jenkins triggered via GitHub Webhook
3. Docker image is built
4. Trivy scans the project
5. Application is deployed on EC2 container
